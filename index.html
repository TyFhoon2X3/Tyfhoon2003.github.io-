เกี่ยวกับฉัน

ยินดีต้อนรับสู่พอร์ตโฟลิโอของฉัน! ฉันเป็นนักพัฒนาเว็บที่มีความหลงใหลในการสร้างประสบการณ์ผู้ใช้ที่ยอดเยี่ยม และแอปพลิเคชันที่มีประสิทธิภาพสูง

ด้วยประสบการณ์หลายปีในการพัฒนาซอฟต์แวร์ ฉันมีความสามารถในการแปลงแนวคิดเป็นโซลูชันดิจิทัลที่ทำให้เกิดความเป็นจริง

ทักษะของฉัน

📱 พัฒนาเว็บ

HTML, CSS, JavaScript, React, Vue.js, TypeScript

🔧 Back-end

Node.js, Python, PHP, MongoDB, MySQL, PostgreSQL

🎨 ออกแบบ

UI/UX Design, Figma, Adobe XD, Responsive Design

🛠️ เครื่องมืออื่นๆ

Git, Docker, Linux, AWS, REST APIs, GraphQL

โครงการของฉัน

🌐 เว็บไซต์อีคอมเมิร์ซ

แอปพลิเคชันอีคอมเมิร์ซแบบเต็มสแต็กพร้อมตะกร้าเก็บสินค้า การชำระเงิน และแดชบอร์ดผู้ดูแลระบบ

เทคโนโลยี: React, Node.js, MongoDB

📊 แอปพลิเคชันบริหารโครงการ

เครื่องมือโดยเด็ดขาดสำหรับทีมเพื่อจัดการงาน ติดตามความคืบหน้า และสง่การทำงานร่วมกัน

เทคโนโลยี: Vue.js, Firebase, Tailwind CSS

🎮 เกมเล่นในเบราว์เซอร์

เกมเล่นในเบราว์เซอร์ที่สนุกสนานพร้อมเอฟเฟกต์ภาพและเสียง

เทคโนโลยี: Vanilla JavaScript, Canvas API
